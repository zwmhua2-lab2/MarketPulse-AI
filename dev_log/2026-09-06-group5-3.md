### P0-2 — 无损规范值（类型标记编码）

`backend/src/marketpulse/g5/canonical.py::canonicalize_value` 从「typed value 折叠为 string」改为**无歧义带类型标记编码**：

```
None → ["null"]；bool → ["bool", v]；int → ["int", v]；str → ["str", v]；
float → ["float", hex]；Decimal → ["decimal", str]；datetime → ["datetime", UTC ISO]；
Enum → ["enum", <canonical value>]；Mapping → ["object", [[k, <canonical>], ...]]（键排序）；
list/tuple → ["array", [...]]
```

- 不四舍五入、Decimal 不经过 float；保持 JSON → UTF-8 → SHA-256。
- `first_snapshot_difference` 感知 tagged 结构：`object` 按 key 递归、`array` 按 index、`scalar` 作叶子，保持语义 path（`$values.fee` 而非 `$values.fee[1]`）。
- `_capture_table` 主键列值保持原始可哈希标量（不再 canonicalize），用于行匹配。
- 无 schema 变更。

新增碰撞回归（`test_group5_3_determinism.py`）：
- `canonicalize(1.0) != canonicalize("0x1.0000000000000p+0")`
- `canonicalize(Decimal("1.2300")) != canonicalize("1.2300")`
- `canonicalize(datetime(...)) != canonicalize(<same ISO text>)`
- `canonicalize(["float", "..."]) != canonicalize(float(...))`
- 源 JSON 形状像 type marker 的对象与真实值保持 distinct
- dict key 排序确定性 / array 保序 / UTC 规范化 / Decimal 精确精度 / float 精确 hex
