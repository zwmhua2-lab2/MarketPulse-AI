## Implementation

- Added explicit `replay_database_url`; `ReplayTradingRunner` requires `RUN_MODE=REPLAY` and never falls back to `database_url`.
- Added `ReplayWorkspaceGuard`: real PostgreSQL `current_database()` identity check, Alembic-head check, clean key-business-table check, and primary row-count fencing before/after replay.
- Added `ReplayMarketState`, `RecordedAIProvider`, and `RecordedPositionReviewProvider`. Both recorded providers only look up the actual snapshot ID and never call real AI or use a fallback.
- Reused `PostgresG2Repository`, `EventRuntime`, `ScannerPipeline`, `DecisionSnapshotBuilder`, `DecisionService`, `TradePlanManager`, `PaperExecutionService`, `SystemRiskGate`, `SafetyRuntime`, `PositionProtectionService`, and `PositionReevaluationService`.
- G3 receives the durable, actual G2 `SETUP` transition through the runner-owned frame result; no scanner/strategy/risk/execution/position business engine was copied.
- Added ReplayClock injection for G3 business writes. G4 keeps its default behavior; only Replay injects a deterministic G4 snapshot ID factory for strict recorded-review lookup.
- Removed `ScannerPipeline.on_apply` orchestration. `ReplayTradingRunner` now owns each frame's G2 completion, BookTicker G4 safety pass, and only then any actual G2 `SETUP` G3 workflow.
- Added PostgreSQL regressions for the reachable Kline `SETUP` ordering and for an existing-position BookTicker path; the latter proves G2 completes before G4 and does not invoke G3 `SETUP`. Added an independent latest-20 timeline query regression and expanded historical-time assertions across persisted G2/G3/G4 facts.
