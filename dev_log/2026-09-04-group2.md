# 2026-09-04 Acceptance Group 2 — 扫描与状态机

## Scope

- 实现 Derived Features、Structure、Scanner、Market Event、Append-style Timeline、async Event Runtime、Symbol State Machine 与 V1 Strategy Candidate。
- 不实现 AI、Trade Plan、Order、Fill、Position、Account、Ledger、Dashboard、Live Trading 或外部消息系统。

## Implementation

- `marketpulse.g2`：内存增量 Rolling Feature Engine，不在每个 Tick 查询 PostgreSQL 历史。
- 独立 Detector 输出市场事实，不输出 BUY/SELL/Open 指令；Liquidation 无数据继续显式 `UNAVAILABLE`。
- Timeline 使用 lifecycle `START`、`STRENGTHENED`、`WEAKENED`、`NORMALIZED`，抑制相同异常刷屏。
- Runtime：有界 asyncio priority queue、有限 worker、同 instrument 串行锁、跨 instrument 并发、Event ID 去重、Late Event 与 expected state version guard。
- State：`IDLE → DETECTED → WATCHING → SETUP`，含失效退回、TTL 与可配置 cooldown。
- Strategy：Trend Pullback、Breakout Retest、Liquidity Sweep Reversal、Zone Absorption Rejection；只输出多个可解释 Candidate，不改 State、不调用 AI、不执行交易。
- Persistence：market_events、signal_timeline_events、symbol_states、state_transitions、strategy_candidates、derived_observations；不持久化 Raw Tick 或完整 Order Book。
