## Scope and Implementation

- `AuthSessionProvider` owns a non-persistent, non-auth-authority `Symbol` generation ref. It advances before sign-out/current authoritative-401 teardown, on successful sign-in, and on Provider unmount so a late client from an older Provider lifetime is stale.
- `createApiClient` uses the existing openapi-fetch per-request `id` only in a transport-local `Map` to capture the generation at protected-request dispatch. A protected `401` invokes `onUnauthorized()` only when that immutable captured generation equals the current one. The map is deleted in both response and error middleware paths.
- No generation is persisted, sent to the backend, derived from the bearer, or used as auth authority. The stable API client continues to read refs rather than rebuild on token/generation transitions.
